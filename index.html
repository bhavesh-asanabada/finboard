steps
How to install the APK:
1. Tap Download APK above
2. Once downloaded, open the file
3. Go to Settings → Apps → Special access → Install unknown apps and allow your browser / Files app
4. Tap Install in the prompted dialog
How to install on iOS:
1. Tap Install on iPhone / iPad above
2. iOS will ask "Would you like to install FinBoard?" — tap Install
3. Go to Settings → General → VPN & Device Management and Trust the developer certificate
4. Open FinBoard from your Home Screen
